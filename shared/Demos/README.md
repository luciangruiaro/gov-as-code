# Demos

**Holds:** demo recordings and the scripts they follow.

**Naming:** `YYYY-MM-DD - <topic>.mp4`, with its script beside it as `YYYY-MM-DD - <topic> - script.md`. A script lists the steps, the data it uses (synthetic only) and the requirement ids it shows (`FR-…`).

**Written by:** people, or a recording tool driven from the governance repo. **Read by:** the client, the team, the daily digest.

**Rules:** demos use synthetic data. Never record a screen that shows customer or end-user data.
