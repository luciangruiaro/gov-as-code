# Team / Ideas

Each person's raw ideas, unfiltered: one file per person, `<Name or role> - ideas.md`, with dated sections, newest first (`## 2026-01-14`). Number ideas `I-01`, `I-02`… within your file, so others can refer to them.

Ideas bind nobody. To ask for a decision, turn an idea into a proposal in [`../Proposals/`](../Proposals/README.md). To explore one, run the `dev-brainstorm` skill in the governance repo: it files its result in `resources/work/brainstorms/`.
