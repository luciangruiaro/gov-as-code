# Decks

**Holds:** presentations: kickoff and workshop decks, steering-committee updates, demo decks, proposals.

**Naming:** `YYYY-MM-DD - <audience> - <topic>.<pptx|gslides|pdf>`, for example `2026-01-20 - Steering - Sprint 3 review.pptx`. Keep the newest version under its date; older drafts go to `Archive/`.

**Written by:** people. **Read by:** the team, and the daily digest, which mentions new decks by name.
