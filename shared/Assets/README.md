# Assets

**Holds:** brand guidelines, logos, fonts, icons, product screenshots, and diagrams exported for slides or documents.

**Naming:** `<kind> - <what>.<ext>`, for example `Logo - primary - dark.svg` or `Brand guidelines v2.pdf`. Screenshots: `YYYY-MM-DD - <screen>.png`.

**Written by:** people. **Read by:** anyone building decks, reports or UI. The design tokens that code uses live in Git: `resources/ui-kit/` in the governance repo.

**Rules:** no screenshots that show customer or end-user data.
