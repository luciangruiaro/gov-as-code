# Brainstorms

Written by `dev-brainstorm`: three to five framings of a rough idea, the tensions between them, one recommendation and the open decisions. The outline is shown in chat and approved before the file is written.

**Layout:** `<YYYY-MM>/<slug>/<slug>.md`. The month is when it started, and the folder holds anything the brainstorm produced beside it.

**Where ideas come from, and where they go:** `Team/Ideas/` on the shared drive (raw) → a brainstorm here (explored) → a proposal in `Team/Proposals/` or an ADR backlog entry (decided) → `dev-plan` (planned). Cite the PRD ids the idea serves.
